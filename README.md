# Exam Countdown + Syllabus Tracker

A mobile-first static study dashboard for UIIC AO, IBPS RRB Officer Scale I, IBPS RRB Office Assistant and GATE 2027 CSE.

## Features

- Live countdown to every exam milestone.
- Live current date/time.
- Days remaining in 2026.
- Expandable syllabus checklist for every exam stage.
- Topic checkboxes with progress saved in browser localStorage.
- No backend, database, login or manual countdown updates required.
- Works on GitHub Pages and can be added to an iPhone Home Screen from Safari.

## Files

- `index.html` — page structure
- `styles.css` — responsive dark UI
- `script.js` — exam dates, syllabus, countdown and progress tracking

## GitHub Pages

1. Create a public GitHub repository.
2. Upload all four files to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Save and open the generated GitHub Pages URL.

## Date notes

- UIIC dates in this tracker are marked tentative because the schedule should be checked against the latest UIIC notice/admit card.
- IBPS RRB XV dates use the 2026–27 IBPS calendar.
- GATE 2027 officially gives an exam window of 6, 7, 13, 14, 20 and 21 February 2027. The CSE entry uses 7 February 2027 as a target and should be confirmed from the final admit card/paper schedule.

## Syllabus note

The checklist is intended as a practical study tracker. The official exam notification/syllabus remains the final authority, especially where an exam body does not publish a detailed topic-by-topic syllabus.
